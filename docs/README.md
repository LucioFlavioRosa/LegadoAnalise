# Sistema de Avaliação - Documentação

Este diretório contém a documentação técnica do Sistema de Avaliação modernizado com Blazor (.NET 9).

## Estrutura da Documentação

- `estrutura-projeto.md` - Documentação da estrutura do projeto e organização de pastas
- `cadastroprojetos.md` - Documentação específica do módulo de Cadastro de Projetos
- `fluxos/` - Diagramas de fluxo em Mermaid dos principais processos

## Convenções

- Todos os componentes reutilizáveis devem ser colocados em pastas `Common`
- Cada domínio deve ter sua própria pasta com subpastas organizadas (Pages, Models, Services, Common)
- Documentação deve ser atualizada a cada nova funcionalidade implementada
